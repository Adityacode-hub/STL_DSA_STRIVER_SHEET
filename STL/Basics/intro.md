 Generic programming enables the programmer to write a general algorithm which will work with all data types.it elimintates the need to create  different algorithm if the data type is an integer ,string or character.


# generic programming is a style of computer programming in which algorithm are written in terms of types to be specified later that are then initiated when needed for specific types provided as parameters.

approcah of generic programming ,pioneered by ML(Meta Language) programming language in 1973.
permits writitng common functions or types that differ only in the set of the types on which they operates when used,thus reducing duplication.
