🧠 Beginner-Friendly Pattern Analysis Methods in DSA

Pattern Name When to Use It Example Problems
1️⃣ Brute Force Try all possibilities; good for understanding the base case Two Sum (naive), all subarrays 2️⃣ Sliding Window Subarray problems (fixed/variable length), especially with positive numbers Max Sum Subarray, Longest Substring Without Repeat 3️⃣ Two Pointers Sorted arrays or when processing from both ends Pair with Target Sum, Reverse String 4️⃣ Hashing (using map/set) When you need fast lookups, detect duplicates, track counts Two Sum (optimized), Subarray Sum = K 5️⃣ Prefix Sum When you’re asked about sum in ranges or subarrays Subarray Sum = K, Range Sum Query 6️⃣ Sorting + Greedy When order matters & decisions must be locally optimal Activity Selection, Minimum Platforms 7️⃣ Binary Search When the array is sorted or the search space is monotonic Search in Rotated Array, Lower Bound 8️⃣ Stack (Monotonic) Problems involving next/previous greater/smaller elements Next Greater Element, Stock Span 9️⃣ Backtracking When you have to try all combinations but can prune branches N-Queens, Sudoku Solver 🔟 Dynamic Programming (Intro) When the problem has overlapping subproblems Fibonacci, Climbing Stairs
